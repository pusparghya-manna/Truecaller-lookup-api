Cookies & Browser Storage

Updated Oct 13, 2026

TrueFind uses only the browser storage needed to remember your preference.

API key storage

Your API key is saved in this browser’s localStorage after you choose to save it. The site sends it in the x-api-key header on lookup requests; it is not stored as an HTTP cookie.

Cookies

TrueFind does not use advertising or analytics cookies.

Clear saved data

Use Manage API key → Forget key, or clear TrueFind’s site data in your browser settings.
